Load a photo, pick a drawing style, tweak until it looks right, export as a path a machine — or a hand — can draw. Built for the Bantam Tools Watercolor Bot, useful for any pen plotter, CNC, or print pipeline.

Overview

RasterVector is a desktop app (openFrameworks / C++) that converts a raster image into vector line art, using one of twenty procedural drawing algorithms — from simple scanline patterns to edge-tangent-flow streamlines and adaptive quadtree patch layouts. The result is a set of paths, not pixels, so it can be sent straight to a plotter, a laser, or a CNC, or dropped into a print layout as clean vector work.

It was built around the Bantam Tools Watercolor Bot, so export, palette handling, and physical scaling (9×12″ at 320 DPI) are tuned for that workflow, but the SVG / GCode / EPS output works with any pen plotter or vector pipeline.

About this page — RasterVector is a personal tool and its source isn't published. This page documents what it does and how it's used, not how to build it.

Workflow

Load

Drop in an image, or load an existing SVG to keep editing a vector drawing already in progress.

Choose a type

Pick one of 20 drawing algorithms (PFM 0–19) — spiral, hatch, streamlines, edge contours, stippling, sparse patch, and more.

Regenerate

Generate the line drawing from the current image and parameters. Runs async — stop mid-generation, tweak, and re-run.

Post-process

Fill shapes, scale to physical size, add brush outlines, thin dense strokes, simplify and clean up paths.

Export

Batch export to SVG, GCode, PNG, and EPS in one go — only the palette colors you've left enabled are included.

16Sparse PatchSparse Patch

Builds an adaptive quadtree over the image: cells with high luminance variance or strong edges split further, flat cells stay large. Small leaf rectangles end up tiling the detail areas while large rectangles fill uniform ones — that structure then drives curve generation. Inspired by He et al., Image vectorization using a sparse patch layout (Graphical Models, 2024).

17–18Sparse Patch Diagonal / Box DiagonalSparse Patch

Same quadtree subdivision as type 16, but instead of tracing curves, each leaf rectangle gets a single diagonal stroke (17) or a box-diagonal stroke (18). Uses the same subdivision parameters.

19Sparse Patch Gradient HatchSparse Patch

Same quadtree subdivision, but each leaf rectangle is filled with gradient-aligned hatching: a structure tensor finds the dominant gradient direction per rect, hatch lines run perpendicular to it, and spacing varies from tight (dark) to wide (light) based on brightness sampled along each line.

Post-process

  • Fill shapes — adds horizontal hatch lines inside closed paths (no outline added; if you see straight "connector" lines, that's the fill).
  • Scale 9×12 — scales the drawing up to 9×12″ at 320 DPI (2880×3840 px), so it's the right physical size for print or plotter.
  • Add brush outlines — adds inset paths after scaling: each stroke gets a random-length segment at a random offset, sized by brush width, with controls for inset × brush, max strokes to outline, and minimum length.
  • Thin: remove 1 out of 2–5 — removes every Nth stroke to reduce density.
  • Plus: remove duplicates, simplify paths, combine same-color strokes, merge brush strokes.
