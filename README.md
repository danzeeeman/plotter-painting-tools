# plotter-painting-tools

Documentation site for two openFrameworks apps by Dan Moore:

- **RasterVector** — turns a photo into vector line art (spirals, cross-hatch, streamlines, edge contours, stippling, isophotes, and more) for a pen plotter, CNC, or print.
- **paintMixer** — extracts a color palette from an image or SVG and works out a real paint-mixing recipe to match it.

Published at GitHub Pages from this repo's root (`index.html`, `rastervector.html`, `paintmixer.html`). Source for the two apps is not included here — this is documentation only.
