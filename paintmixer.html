Overview

paintMixer takes any image or SVG, clusters it down to its dominant colors, and then solves — for a chosen physical paint set — the closest mixing recipe for each one: which two, three, or four paints to combine and in what ratio. The output is a step-by-step recipe you can actually mix at a palette, plus a rewritten SVG or remapped image so you can preview the piece in the colors you'll actually be able to make.

About this page — paintMixer is a personal tool and its source isn't published. This page documents what it does and how it's used, not how to build it.

Workflow

Open

Load an image or an SVG file (O, or drag onto the window).

Extract

Cluster the file down to its dominant colors — k-means in CIELAB space, or every exact color from an SVG's fills/strokes.

Adjust

Nudge brightness, contrast, hue, and saturation globally or per extracted color before mixing.

Mix

Pick a physical palette — built-in or your own — and get a weighted recipe for each extracted color.

Export

Recipe PDF, Bantam Tools toolset JSON, a palette-remapped SVG or PNG, or all of it at once.

Color extraction

From an image: pixels are sampled (up to 50,000), converted to linear RGB, and clustered with k-means (sorted by luminance first, for tonal-band initialization; up to 40 iterations). A merge delta slider then greedily folds together any two resulting colors closer than that sRGB distance, so near-duplicates collapse into one swatch. Max colors (4–64) and iterations (1–64) are adjustable before extraction.

From an SVG: fill/stroke colors are parsed straight out of the XML — no geometry tessellation needed — and clustered the same way, unless "Every color (no clustering)" is on, which returns every unique color used with no reduction.

A grayscale palette toggle strips hue entirely, useful for value studies or ink work.

Global & per-color adjustment

Before extraction, global sliders shift the whole source: brightness, contrast, hue, and saturation (×). After extraction, each individual swatch can be nudged the same way — hue, saturation ×, brightness × — with a one-click reset per color, so you can correct a single mis-clustered color without redoing the whole extraction.

Custom palettes

Load a palette from a file, or build one by hand: Load file... reads a swatch list, Add appends a color, Clear all starts over. Useful for matching a specific paint set you own rather than a generic one.

Mixing recipes

For each extracted color, paintMixer tries every combination of 2, 3, and 4 colors from the active palette and keeps whichever combination — and ratio — comes closest in linear RGB (L2 distance). The result is a MixingRecipe: a target color, the blended result the recipe actually produces, and a list of components sorted by weight (e.g. "Start with 60% Cadmium Yellow, add 25% Burnt Sienna, add a touch of Ivory Black (15%)").

A batch size slider (5–200 g) scales every recipe's percentages up to an actual quantity to mix, and nearest palette color lookup finds the single closest swatch when you just want a quick match instead of a blend.
