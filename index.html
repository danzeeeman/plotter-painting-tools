Tools for getting images
onto paper, one way or another.

Two small C++ apps built for a pen plotter and a Bantam Tools Watercolor Bot: one turns a photo into a line drawing it can draw, the other turns a photo into a paint recipe you can mix by hand.

Image → line drawing

RasterVector

Turns a photo into vector line art using twenty different drawing styles — spirals, cross-hatch, streamlines, edge contours, stippling, isophotes — then exports SVG, GCode, EPS, or PNG for a plotter, CNC, or print.

Image → paint recipe

paintMixer

Extracts a dominant color palette from any image or SVG, then works out how to mix each color from a real set of watercolors, acrylics, or markers — with step-by-step ratios and a printable recipe card.
